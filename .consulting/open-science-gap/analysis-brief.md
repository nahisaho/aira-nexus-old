# Open Scienceとの要件差分調査

調査開始時の18要件には、研究の実行過程を追跡する条件と、中断から安全に復帰する条件が不足していました。参照実装を丸ごと移植せず、MVPに必要な受入条件を選んで補完することを推奨しました。

- 分析担当: Copilot
- 意思決定者: サービスの要件決定者
- 判定時点: 2026-11-08、実装開始前
- 成果物: 要件差分の分析。実装仕様や承認の代替ではありません。
- 状態: Ready for Handoff

## 決定する問い

要件決定者は、認証なし・単一ユーザーのAI for Science MVPに、どの不足条件を追加するべきか。

## 対象と制約

| ID | 条件 | 根拠 | 分析への影響 |
| --- | --- | --- | --- |
| CON-001 | Next.js、TypeScript、PostgreSQL、GitHub Copilot SDKを使用する | 今回のユーザー回答 | Electron、SQLite、ACPへの置換は対象外 |
| CON-002 | localhost限定。Entra IDとマルチユーザーは後続段階 | 今回のユーザー回答 | 参照先のリモート公開・モバイル接続は採用しない |
| CON-003 | 同じNotebookでPythonとRを混在させ、明示した変数を共有する | 今回のユーザー回答 | 言語別Notebookへの分割では代替できない |
| CON-004 | コードは毎回確認後にコンテナで実行し、外部通信を禁止する | 今回のユーザー回答 | 参照先のネットワーク許可・シェル実行を自動採用しない |
| CON-005 | 5仕様ファイルは未承認。実装は保留する | 承認フォームへの回答 | 調査結果だけで仕様を変更・承認しない |

## 調査の基準

調査開始時の5仕様に受入条件があるかを確認し、参照先の型・処理・テストで具体的な挙動を照合しました。READMEの機能数やベンチマークは、実装済み・安全性・科学的妥当性の証明として扱っていません。

参照先は `References/open-science/` に読み取り用としてcloneしました。調査対象commitは `0cdaef53a539588a44d12390aebdcadccda27df9` です。`.gitignore` は `References/` 全体を除外します。参照先のインストールスクリプト、ビルド、テストは実行していません。

## 使用する分析方法

| 方法 | 用途 |
| --- | --- |
| Issue Tree | 入力、操作、実行、研究記録、運用の各段階で不足を確認する |
| Current–Target–Gap | 現在の契約と、MVPで必要な観測可能な結果を比較する |
| Pyramid Principle | 不足条件、根拠、採用判断を分けて伝える |

## 未決事項

AIのNotebook操作範囲、Python/Rの欠損値変換、データ容量、会話セッション数は製品判断が必要です。参照先の実装は選択肢の根拠ですが、こちらの要求を決定するものではありません。

## 調査後の決定

ユーザーは9項目の基本条件、確認を経るAI操作、明示した内容だけの結果送信、欠損値と型・形状・列名の保持、100 MiBファイル／256 MiB実行入力、複数の名前付き会話を選びました。現在の実装契約は12仕様・39要件の未承認ドラフトです。型変換・大きなファイル転送・外部Jupyter互換性の追加spikeは未実施です。
