## Design
Streaming raw upload and bounded storage writes; immutable owned version identity is separate from filename. A selection maps each version to one unique safe workspace basename. Serialize quota reservations/publication against the active project: pending upload/harvest bytes count toward the 2 GiB file quota, and archive/overflow/failure cannot publish a partial version. Never use user filenames as host paths.
Workspace Markdown uploads may prepare a YAML-bearing Blob under REQ-MARKDOWN-002 before invoking the unchanged byte-preserving upload API. Hashes, quotas and downloads bind those actual submitted bytes; neither the original local file nor older immutable versions are rewritten.
Streaming upload and worker file transfer are separate from small SDK text-tool arguments/display limits. Worker chunks bind transfer ID/offset/hash/ack; <=512 KiB raw and <=1 MiB encoded. Verify total hash/size; partial upload/staging/harvest is never a visible complete version.
`GET /api/projects/:projectId/files/:fileId/image` is the explicit image-viewing exception for Markdown embeds and SVG file tabs, not a relaxation of `/preview` or `/download`. It uses the same local-boundary and owned-project lookup, verifies the stored hash and returns only `image/png` with existing local response protections. PNG/JPEG inputs use the established signature, dimension, single-page and re-encoding checks. SVG inputs allow static shapes, groups, paths, text, gradients and clipping with presentation attributes; reject script, foreignObject, image/use, style/event/href attributes, animation, DTD/entities and processing instructions after an optional XML declaration. Only internal `url(#id)` references are permitted; external/data/file references are forbidden. Budget violations return 413, forbidden features/unsupported image types return 415, and rasterization failures return 422. Raw immutable downloads retain octet-stream attachment delivery and exact original bytes.
Image responses explicitly retain `X-Content-Type-Options: nosniff`, same-origin resource policy and deny framing; no active SVG response is created. Invalid UTF-8/signature mismatch is415; syntactically malformed XML or otherwise corrupt raster content is422; missing/unresolvable SVG dimensions are422, resolved over-budget dimensions413. SVG with only a valid viewBox may use its resolved intrinsic dimensions; no inferred unlimited canvas is allowed. Hash mismatch preserves existing503 `FILE_INTEGRITY_ERROR` before conversion, distinct from503 `IMAGE_PREVIEW_BUSY` admission refusal.
Use bounded FIFO rasterization admission shared by image-route requests in this app process: two active, eight waiting, maximum ten-second queue wait; no unbounded retry/queue and no global-host process control. Validate bounded input before heavy rasterization, recheck cancellation before starting and release exactly once on success/error/cancel. The queue is not an OS-memory/CPU sandbox. `TEST-DATA-004` owns byte/node/pixel boundaries, invalid encodings/content/statuses, viewBox/no-dimension and response-header cases; planned `TEST-DATA-005` owns deterministic overlapping-job admission, FIFO release, queue overflow/expiry/cancellation and real image-route integration. Its implementation/evidence is pending, not an existing passing test.
## Assumptions / risks
Text preview first 64 KiB with explicit omission; raster preview <=10 MiB with validated PNG/JPEG signature/MIME, dimensions <=8192 each and <=32 million decoded pixels, never SVG/HTML relabeling. Browser tests must exercise hostile MIME and decompression budgets; preview refusal retains exact download bytes. Project immutable-file quota is 2 GiB including pending reservations, not an unlimited record/storage guarantee. PDF/Office/molecular viewers deferred.
The shared SVG image path performs real validation/rasterization, not MIME relabeling or raw SVG embedding. Its native decoder timeout is not OS isolation. TEST-DATA-003 was re-run and passed alongside the new data/browser media tests on 2026-11-11; this does not renew other historical capacity evidence or formal approvals.
